## Featured Projects

These projects are on the site, and all of them are on [github.com/LegradiK](https://github.com/LegradiK?tab=repositories):

- **[KS1 Learning Hub](https://github.com/LegradiK/ks1_learning_hub)**: a Flask web app where children aged 4–7 can learn, play and log their reading, aligned with the UK KS1 curriculum. It has child accounts with PIN sign-in, progress reports, a My Bookshelf reading tracker using the Google Books API, and games covering spelling, phonics, arithmetic, reading comprehension, logic, money, telling the time and memory. Built with Flask blueprints and an app factory pattern.
  ↗ [Live site](https://kidslearninggames.pythonanywhere.com/) (demo login: username `test`, PIN `1234`)

- **[Library Book Renewal Automation](https://github.com/LegradiK/library_books_renewal_automation)**: a Python/Playwright tool that renews library books on Spydus and BorrowBox. It runs daily on GitHub Actions, handles credentials for several users with environment-scoped secrets, and uses screenshots to debug CI runs.

- **[Menu Planner](https://github.com/LegradiK/menu-planner-2)**: a Flask app that plans a week of meals from 130 recipes and turns them into a smart shopping list with cleaned-up, merged and categorised ingredients. It includes Flask-Login accounts, a SQLite/SQLAlchemy calendar of past menus, CSRF-protected forms, Pylint in CI, and a GitHub Actions workflow that emails a new menu every Friday.
  ↗ [Live site](https://kahopythonbookshelf.pythonanywhere.com/) (free hosting, so the first load may take 30–60s)

- **[Horizon Intelligence: Space Dashboard](https://github.com/LegradiK/all_about_space_web_app)**: a Flask/Jinja2 dashboard that pulls live data from NASA APOD, EPIC and NeoWs, Launch Library 2, AuroraWatch UK and ISS tracking, with interactive D3.js visualisations.
